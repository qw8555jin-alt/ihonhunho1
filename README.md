# 이혼전문 변호사 숏폼 마케팅 솔루션

## 프로젝트 소개
본 프로젝트는 이혼 전문 변호사를 위한 맞춤형 숏폼 마케팅 안내 및 신청 웹사이트입니다. 단순 조회수가 아닌 **실제 수임률 증가**를 목표로 하는 원피드마케팅의 핵심 전략과 서비스 가치를 전달합니다.

## 주요 기능
- **직관적인 메인 카피**: 레퍼런스(groweb) 스타일을 차용하여 강력하고 직관적인 '수임률 증가' 메시지 전달.
- **자동 스크롤 풀화면 배경**: 전체 화면을 덮는 고화질의 로펌 관련 이미지 배경이 5초 간격으로 자동 스크롤(페이드-슬라이드)됩니다.
- **반응형 디자인**: 모바일, 태블릿, PC 등 어떤 디바이스에서도 완벽하게 최적화된 화면을 제공합니다.
- **마케팅 진단 신청 폼**: 
  - 과거 숏폼 진행여부, 현재 운영 채널 등 마케팅 전략 수립에 필요한 데이터 수집.
  - 심리적 거부감을 줄이기 위해 월평균 수임 건수 및 평균 착수금을 '선택형 객관식'으로 배치하고, 명분을 안내.

## 기술 스택
- **Framework**: Next.js (App Router)
- **Styling**: CSS Modules (Custom Properties & Animations)
- **Form Handling**: Netlify Forms 연동 지원 (data-netlify="true")

## 로컬 실행 방법
```bash
npm install
npm run dev
```

## 배포 및 빌드
```bash
npm run build
npm start
```
