# 이혼 전문 변호사 숏폼 마케팅 제안 (원피드마케팅)

본 프로젝트는 이혼 전문 변호사를 타겟으로 한 숏폼 마케팅 전문 대행 서비스(원피드마케팅)의 공식 홈페이지(랜딩 페이지)입니다.

## 주요 기능 및 특징
1. **히어로 섹션 (Hero Section)**: 직관적인 카피라이팅("오직 수임률 증가입니다")과 반응형 애니메이션.
2. **솔루션 안내 (Agitation & Solution)**: 변호사들의 공통적인 마케팅 고민을 짚어주고, 1:1 맞춤 승소 데이터 분석 및 하이-훅(High-Hook) 기획 등의 솔루션을 제시합니다.
3. **고객 후기 (Social Proof)**: 다수의 성공 사례(Case A ~ J)를 직관적인 무한 스크롤(Marquee) UI로 배치하여 신뢰도를 극대화했습니다.
4. **문의 폼 (Contact Form)**: 변호사의 월평균 수임 건수, 평균 착수금 등을 부담 없이 입력할 수 있는 사용자 친화적인 신청폼을 제공하며, 개인정보 수집 동의 UI를 포함하고 있습니다.
5. **마케팅 성과 추적**: 메타(Meta) 픽셀을 연동하여 페이지 방문(PageView) 데이터를 추적합니다.

## 기술 스택
- Next.js 15
- React 19
- 순수 CSS (CSS Modules)

## 개발 및 빌드
```bash
npm install
npm run dev
npm run build
```
